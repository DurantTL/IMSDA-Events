# Site rules

Every rule Caleb has approved for how the site looks and behaves, one line each,
in his wording where he gave it. Reviews and builds check changed pages against
this list (see `AGENTS.md` → Checks and `.agents/skills/imsda-review/`).

- **Adding a rule:** a newly approved rule is added here in the same PR that
  builds it, with its issue number.
- **Guard test:** a code check (Vitest or a `scripts/` check) that fails when
  the rule is broken. "planned (#NNNN)" means the issue that builds the rule
  also builds its guard and it does not exist yet (today only B3). "browser test
  only" means no code check can see the rule.
- **Reviewed lists:** some guards keep a short list of older exceptions (in the
  test, or in a `tests/fixtures/*-1440.json` file), each with a reason or a
  recorded count. A new break fails; folding an old exception into the shared
  version is how the list shrinks.
- **Browser test:** a check that uses the page in a real browser.
  "planned (#1439)" means it does not exist yet. The mobile layout audit is
  `npm run test:mobile-layout` (`scripts/verify-mobile-layout.ts`). The role
  journeys suites are `npm run test:club-journeys` (`scripts/verify-club-journeys.ts`,
  the required CI check "Club journeys (real browser)"): club directors and area
  coordinators use the site in Chromium at 1280 and 390 px wide, and every page
  they visit is checked against the rules listed here for it; and
  `npm run test:event-journeys` (`scripts/verify-event-journeys.ts`, the CI checks
  "Event journeys (real browser, desktop)" and "(real browser, phone)"): an
  attendee creates an account, registers with a promo code and pays by card,
  manages the registration and asks to cancel it, and event staff (as stamped
  synthetic users) create an event from a template, publish it, test the form,
  work the attendee list, check people in and schedule an email, at the same two
  widths. System administrator journeys are round 3.
- **Rule IDs** (G1, S1, …) are what a review report names when it lists the
  rules it checked.
