The CSS-only IMSDA Events mark: a gold tile with an italic Georgia "i" and a purple disc in the corner, beside the two-line wordmark.

- Built from `.brand`, `.brand-mark` and `.brand-flame`; there is no SVG or image logo in the repository.
- Tile is `--imsda-gold` with `--imsda-navy-deep` letterform; the disc is `--imsda-purple` at 90% opacity.
- Use it once per header. On the navy sidebar the small line uses a lighter tint (`#a9c0ca`).
- Do not recolor the tile or swap the serif; the italic Georgia "i" is the only serif in the product.
