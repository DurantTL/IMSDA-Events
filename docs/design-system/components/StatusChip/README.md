Pill labels that state a record's status in a real word, plus the navy count badge.

- Tones: `green` done (Submitted, Registered), `gold` in progress (Draft, Waitlisted), `purple` informational (Invited), `coral` needs attention (Expired), `neutral` not started.
- Text is always the status word; color never carries meaning alone.
- `.count-badge` shows a number with its noun ("24 members").
