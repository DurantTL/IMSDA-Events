Mockup of the month calendar: a ruled grid with toned event chips and a key.

- Chips bind to `--cal-tone-1`…`6` fill/edge/ink, a solid navy `calendar-tone-event` for conference events, and `--cal-closure-*` for office closures.
- Each chip has a 3px colored left edge and text, so tones are never the only cue; the key repeats each tone with its name.
- Today's date is a navy circle. Days outside the month use a lighter fill.
