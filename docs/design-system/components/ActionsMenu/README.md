A disclosure menu (`<details>`) that collects a row's less common actions behind one **Actions** button.

- Trigger is a `.secondary-button`; when open it takes `--imsda-navy-soft` and a navy border.
- Items are 40px rows; the destructive item sits last, below `.actions-menu-divider`, in `--danger`.
- Use it when a row has three or more actions; keep the most common action visible beside it.
