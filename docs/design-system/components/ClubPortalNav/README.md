The club portal header: white masthead, navy club banner and a single flat tab row with every club tool.

- Ten tabs, in order: Home, Roster, Forms, Club events, Honors, Class tracking, Monthly Records, Orders, Health, Club settings. There is no "More" menu; the strip scrolls sideways on phones.
- Tabs are 48px tall, `--muted` text; the current tab has `aria-current="page"`, `--imsda-navy` text and a 3px `--imsda-purple` underline.
- Masthead: the IMAdventist symbol with "Club portal" (coordinators see "Club coordination"), the signed-in name and role, and 44px outlined actions: **Your account**, **Forms help**, **Sign out** (plus **Switch club** for people with more than one club).
- The navy banner names the club, its church and the person's role, with the club year in an outlined box on the right.
