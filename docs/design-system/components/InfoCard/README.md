Event info cards for public event pages: a toned left edge, an uppercase tone label, a heading and short text.

- Tones: neutral, `is-info`, `is-deadline`, `is-requirement`, `is-success`, `is-help`, each bound to `--info-card-*-bg` and `--info-card-*-edge`.
- These are one of two token sets with dark values (see the theme switch); body copy uses `--info-card-ink`.
- Use one card per fact; don't stack more than four in a row.
