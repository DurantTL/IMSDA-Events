# Reporting a security problem

IMAdventist holds personal information about church members, including children. If you find a way to see or change something you should not be able to, please tell us privately so it can be fixed before anyone else learns of it.

## How to report

- On GitHub, open this repository's **Security** tab and choose **Report a vulnerability**. Only the maintainers can read what you send.
- If that button is not shown, contact the Iowa-Missouri Conference Communication Department ([imsda.org](https://www.imsda.org)) and ask for the events site maintainer. Do not include the details in a public message.

Please do not open a public issue, pull request or discussion about a security problem.

## What to include

- What you were able to do, and as which kind of user (visitor, attendee, club director, staff).
- The page or address involved and the steps to repeat it.
- Use test or made-up information only. Do not open, copy or keep anyone's real records.

## What happens next

We will reply as soon as we can, tell you what we found, and say when a fix is live. This is a small project of a church conference; there is no reward program.

## Scope

The application in this repository as it runs at `events.imsda.org`. Other conference websites and third-party services (Square, Cloudflare, email providers) should be reported to their own owners.
